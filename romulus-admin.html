Cómo conectar Sheets

1. Abre el archivo romulus-apps-script.gs del repo.
2. Cópialo en Google Apps Script.
3. Pega el ID de tu Google Sheet.
4. Crea Script Property ADMIN_TOKEN.
5. Ejecuta setupSheets() una vez.
6. Deploy como Web App y pega el URL arriba.
